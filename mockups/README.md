# v0 Mockup — June 8 NABU Meeting

## Purpose

This mockup is a discussion artifact for the June 8 NABU meeting.

It is intended to help NABU react to the proposed August MVP direction:
- map-centered layout,
- species/year controls,
- federal-state counts,
- basic observation display,
- attribution,
- open scientific and technical questions.

This is **not** a final design and **not** a production implementation.

## Current assumptions

- Germany-first view for the August MVP
- GBIF / NABU-naturgucker data as source
- One selected year at a time unless NABU/scientific input says otherwise
- Species toggle available
- Federal-state counts shown as a sidebar or panel
- iFrame/embed direction still needs NABU technical confirmation
- Exact production stack still needs NABU technical confirmation

## Files

- `index.html` — static mockup / preview
- `screenshot.png` — screenshot for quick review
- `mockup-notes.md` — what is shown, assumptions, and questions for NABU

## Not included

- Full data pipeline
- Final map implementation
- Final design
- Advanced research layers
- Habitat/climate/population-density filters
- Complex species-overlap logic
- Production hosting
