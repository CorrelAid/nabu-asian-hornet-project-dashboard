# v0 Mockup Notes — June 8 NABU Meeting

## What this mockup shows

This mockup shows a possible structure for the August campaign MVP:

- Germany-centered interactive map area
- Species control for:
  - Asian hornet
  - European hornet
  - nests
- Year selector
- Federal-state observation counts
- Basic legend
- Data attribution placeholder
- Draft/not-final label

## What is sample/fake

The following elements are placeholders and should not be treated as final:

- sample data points
- visual styling
- colors
- exact legend text
- exact count values
- final map behavior
- final attribution wording

## What we want NABU to validate

1. Is this general layout direction useful?
2. Is Germany-first acceptable for the August MVP?
3. Should users select one species at a time, or should both hornet species be visible together?
4. If both species are visible together, how should overlap be defined and shown?
5. Is a single-year selector acceptable for v0?
6. Should the sidebar show federal-state counts?
7. What attribution text is required?
8. Are there design/accessibility constraints we must follow?
9. Is iframe embedding still valid after the website relaunch?
10. Who at NABU owns hosting and maintenance after handover?

## Known blockers

- NABU website stack not confirmed
- iFrame / CSP / embed policy not confirmed
- Hosting/deployment model not confirmed
- GPS precision / privacy rule not confirmed
- Exact GBIF dataset key/source-of-truth not confirmed
- Final design guidelines not shared
- Scientific decision on species overlap not made

## Proposed August MVP boundary

Included:
- map-centered view
- Germany-first
- species/year controls
- federal-state counts
- basic observation display
- data attribution

Excluded for August:
- habitat filters
- climate filters
- population-density filters
- Research-derived analysis layers
- complex multi-year trend overlays
- full production automation if NABU hosting/scheduler is unclear
